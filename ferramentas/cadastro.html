Cadastrar uma peça nova

Preencha os campos, copie o texto que aparece no fim da página e cole dentro do arquivo dados/produtos.js, logo depois do "produtos": [. Não precisa entender de programação — é copiar e colar.

Cole este trecho no arquivo dados/produtos.js

  1. Salve a foto quadrada em assets/img/produtos/ com o nome que você escreveu acima.
  2. Salve também uma versão menor com -600 no fim do nome (ex.: bolsa-tote-azul-600.jpg). Se não tiver, o site usa a foto grande mesmo.
  3. Abra dados/produtos.js, cole o trecho logo depois de "produtos": [ e salve.
  4. Envie os arquivos para o site.
