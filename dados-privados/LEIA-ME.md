# Dados do negócio

Esta pasta guarda os arquivos que o painel usa. **Não apague nada daqui.**

| Arquivo | O que é |
|---|---|
| `pedidos.json` | todos os pedidos feitos pelo site |
| `clientes.json` | lista de clientes (módulo de marketing) |
| `custos.json` | despesas lançadas no financeiro |
| `posts.json` | textos do blog, publicados ou não |
| `campanhas.json` | campanhas e cupons |

**Backup:** uma vez por mês, baixe esta pasta inteira e guarde. É o histórico
financeiro do negócio; se sumir, não tem como recuperar.

O arquivo `.htaccess` impede que qualquer pessoa abra esses arquivos pelo navegador.
Não apague esse arquivo.
